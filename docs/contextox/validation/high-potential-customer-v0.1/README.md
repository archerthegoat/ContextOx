# 高潜客户规范验证包 v0.1

这是为 ContextOx（数契）创建场景准备的自有静态测试材料，不是客户案例、真实经营数据、已批准规范或可运行产品 demo。权威方向与决策仍在[架构报告](../../产品形态与执行架构决策-v0.1.md)；本文件只说明材料怎么读、怎么核对。

## 三分钟入口

1. 先读 [input/context.md](input/context.md)：模拟目标、五组来源的字段含义、未知、角色与权限边界。
2. 再看 [input/facts.json](input/facts.json)：未经分群的原始合成事实；没有 RFM 答案、客户标签、评分公式或 Contract。
3. 最后读 [质量报告](evaluation/quality-report.md)：实际离线核对和剩余缺口；产品/模型/权限隔离测试仍为 NOT_RUN，人类产品验收仍为 PENDING。

整个 README、manifest、质量报告、场景断言和架构报告只给编制/评估端看，不作为未来产品 Agent 的初始输入。

## 时间、单位与已知缺口

- 基线和未见集均为 UTC、CNY 整数分。货品行金额与运费各自是行总额，支付是独立收款；不能先多对多联结再求和。
- 观察窗为 [2026-04-01T00:00:00Z, 2026-07-01T00:00:00Z)，T0 为 2026-07-01T00:00:00Z。available_at ≤ T0 才属于主视图。T1=2026-07-04T00:00:00Z 只用于评估副本中的迟到反例，不改原 T0。
- 映射适用时间和事件观察窗不同；窗口前有效、T0 仍适用的映射保留。商品行没有独立购买时间时，只有明确父订单依据才可继承，同时独立检查行版本可获得时间。
- 混币、跨时区、缺失/重复/孤儿和未来可获得版本只在 cases 的独立材料中，不污染两个基线。
- 退款覆盖、成本、利润、未来购买及完整终身历史未提供；缺少 delivered 事件也不等于未交付。未知不填 0，不等于低潜，也不能无条件阻塞不依赖它的合法运营规范。
- 所有业务时刻都是合成时钟；实际文件编制和离线检查时刻另行记录，不能冒充真实历史采集或当前经营新鲜度。

## 独立评估约定

本包 heldout 只供独立受控消费者，在规则/映射和评估协议固定后按确切快照、主体和当前授权复算。不得进入初始设计 Agent、模型训练、调参、适应或生产消费。作者和离线检查器可以看到它；未来消费后必须记录曝光，重复使用不能继续称“未见”。

字段改名、目标或容量变化使用明确标记的主样本副本。这些副本可以测试对应变化，但已经曝光，不足以证明真实模型对未见业务的泛化；该项需要以后另备未曝光材料与授权。

cases 的 data_recipe 是评估端的有限材料复制说明，不是产品工具/API。每个变体从新副本开始；material_expected 检查材料构造，expected_behavior / forbidden_behavior 留待产品接缝实施后执行。控制场景的对象、批准和任务身份均为符号前提，未生成实际 Contract、签名或内容指纹；未来测试装置须先建立真实有效前置状态。

## 来源、责任与重置

- 来源：本任务明确枚举数值并机械展开的合成资料；未使用 Olist、外部数据行、个人身份或账号，不做随机采样。
- 仓库 [LICENSE](../../../../LICENSE) 当前标为 MIT；本轮不修改许可证、不新增许可声明或第三方数据分发承诺。
- 本轮主 Agent 负责静态材料与复核方法；独立 LunaMax 只读审查，不是运行期 Owner。未来业务责任人、运行装置和生产维护人须另定。
- manifest 对另外六份文件的原始 UTF-8 字节计算 SHA256；不自包含自身哈希，也不循环包含架构报告哈希。manifest 的最终哈希和封装读回记录在架构报告本轮回执。
- 哈希用于识别这次材料和检查，不能冻结公共 Schema 或代表人类验收。修订枚举/断言必须记录原因、换版本或重新生成哈希并复核，旧记录不伪造为新版结果。
- 没有启动服务、数据库、模型或产品会话，没有业务运行状态需要 reset。离线脚本仅在内存复制样本，退出即丢弃副本；不要清理共享工作区，也不要删除其他任务的临时文件。
